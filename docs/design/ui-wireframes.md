# AssestBundleTools 文本原型

## 1. 说明

本文档用于通过文本线框表达当前有效 UI 结构，方便在继续实现前快速讨论布局与交互。

本文档已经同步到当前收敛方案：

- 单主窗口
- 控制台页 + 三栏工作台
- 资源包标签页
- 资产列表多选
- 设置与诊断承载详细日志

如与其他文档冲突，以 [ui-final-spec.md](C:/Users/thixi/source/repos/AssestBundleTools/AssestBundleTools/docs/design/ui-final-spec.md) 为准。

## 2. 符号说明

- `[按钮]` 表示可点击命令
- `(页签)` 表示页面级页签或检查器选项卡
- `{标签}` 表示状态徽标或摘要项
- `...` 表示内容省略

## 3. 应用外壳

```text
+------------------------------------------------------------------------------------------------------+
| AssestBundleTools                                                                     [_][□][X]      |
+----------------------+--------------------------------------------------------------------------------+
| 控制台 / 工作台      | 页面标题 / 页面操作区                                                           |
| 批处理任务           | 页面主体                                                                       |
| 设置与诊断           |                                                                                |
+----------------------+--------------------------------------------------------------------------------+
```

补充说明：

- 一级导航第一入口位在无工作区时显示“控制台”，进入工作区后显示“工作台”
- 控制台默认在应用刚启动时显示，也允许从工作台显式返回

## 4. 页面职责

- 控制台页：启动入口、最近工作区、最近操作
- 工作台：资源包浏览、标签页、资产列表、资源详情
- 批处理任务：批量提取、批量替换、保存前摘要
- 设置与诊断：详细日志、环境检查、后续语言设置

## 5. 页面原型

## 5.1 控制台页

```text
+------------------------------------------------------------------------------------------------------+
| 控制台                                                                                               |
| 从这里开始创建、打开或恢复工作区。确认后会进入正式工作台；如有需要，也可以从工作台返回这里重新整理入口。|
+------------------------------------------------------------------------------------------------------+
| [新建工作区]   [打开工作区]   [打开最近工作区]                                                        |
+------------------------------------------+-----------------------------------------------------------+
| 最近打开                                 | 最近操作                                                  |
| - DemoWorkspace                          | 20:16  提取了 3 个 Texture2D 资源                         |
| - D:\game\ab\ui\                         | 19:42  替换了 ui_common.ab 中 1 个 TextAsset              |
| - E:\test\bundle\effects.ab              | 19:15  输出新包到 D:\output\                              |
```

说明：

- 这一页默认在应用启动阶段显示
- 真正高频工作流在工作台完成
- 当前窗口进入工作区后仍可通过显式按钮返回这里

## 5.2.3 资源包列表搜索展开态

```text
+-----------------------------+
| 资源包列表   [收起]         |
| [ 搜索资源包名称或路径...... ]|
|                              |
| > ui                         |
|   - ui_common.ab             |
|   - ui_login.ab              |
+-----------------------------+
```

说明：

- 搜索框默认收起，点击搜索按钮展开
- 收起 / 展开按钮使用左右箭头语义，而不是额外的功能型图标
- 展开与收起使用轻量动画
- 搜索结果仍保留分组选中反馈

## 5.2.4 资源包列表收缩态

```text
+----------+------------------------------------------+------------------------------------------+
| [展开]   | (ui_common.ab) (battle.ab)              | 资源详情                                  |
|          |                                          |                                          |
| 14       | [搜索资源...] [类型▼] [仅已修改]        | [预览占位区域]                           |
| 资源包   |                                          |                                          |
|          | 名称         类型         状态           | 名称: hero_icon                          |
| 3        | hero_icon    Texture2D    {原始}        | 类型: Texture2D                          |
| 分组     | title_txt    TextAsset    {已修改}      | 所属: ui_common.ab                       |
|          | ...                                     | 路径: assets/ui/...                      |
| UI       |                                          |                                          |
| 当前     |                                          | [提取] [工作区来源] [选择文件来源]       |
+----------+------------------------------------------+------------------------------------------+
```

说明：

- 收缩后左侧不消失，而是保留一个摘要窄条
- 窄条显示资源包总数、分组数量和当前选中资源包缩写
- 收起与展开过程需要带有列宽过渡和卡片淡入动画
- 收缩后中间资产列表与右侧资源详情均分剩余宽度

```text
+--------------------------------------------------------------+

| 已选中 3 项                                         [提取选中]|

| title_txt         TextAsset       {原始}                      |
```

说明：

- 多选快捷操作只在选中数量大于 1 时显示
- 当前只保留 `提取选中`
- 单资源编辑仍在右侧检查器完成

## 5.2.6 顶部浮动提示

```text
                                 +--------------------------------------------+
                                 | [成功图标] 操作完成                     x   |
                                 | 已完成 3 项资源的提取标记。                |
                                 +--------------------------------------------+
```

说明：

- 采用顶部悬浮 toast，而不是页面内嵌提示块
- 关闭按钮为无背景 `x`
- 需要轻量入场和退场动画

## 6. 交互摘要

当前页面级交互规则如下：

1. 单击左侧资源包项：直接打开或激活对应标签页
2. 同一资源包在同一工作区内只保留一个标签页实例
3. 资产列表支持扩展多选
4. 多选后在列表内部显示 `提取选中`
5. 单资源替换与撤销统一在右侧检查器执行
6. 详细日志统一查看“设置与诊断”

## 7. 当前不纳入原型范围

当前文本原型明确不再包含：

- 资源子窗口浏览
- 主界面双窗格对比
- 依赖树主工作流
- 页面底部大日志面板
- 主工作区中的嵌入式成功提示块
