# 在线组件安装与运行时依赖恢复

## 1. 文档目的

本文档定义应用在缺少可选运行时工具时的统一恢复链路。第一项落地能力是为 FSB5 音频预览安装官方 `vgmstream-cli`；后续在线插件目录、资源处理器或其他可选工具应复用同一下载、校验和安装边界，不在页面或单个预览器中重复实现网络下载。

## 2. 当前行为

- FSB5 等需要外部转码的音频仍先通过正常预览管线生成结构化摘要。
- 当摘要明确携带可恢复组件 id，且请求是用户正在查看的前台预览时，Presentation 才允许弹出安装确认；后台预热、批处理和缓存构建不得弹窗。
- 用户拒绝或关闭确认后保留现有摘要，不把拒绝视为预览异常；同一组件在当前应用会话内不再重复询问，重启应用后可以重新确认。
- 用户确认后，在后台下载并安装组件；安装成功后立即重新请求当前资产预览。预览缓存继续通过已有转码器 descriptor/version 规则自动升级，不由 UI 直接删除缓存文件。

当前内置注册项：

| 组件 id | 用途 | 来源 | 安装目录 |
| --- | --- | --- | --- |
| `runtime.vgmstream-cli` | FSB5 音频解码为 WAV | `vgmstream/vgmstream-releases` 官方 GitHub nightly Windows ZIP | `%LOCALAPPDATA%/AssestBundleTools/tools/vgmstream` |

应用安装包不直接捆绑 vgmstream。确认界面必须展示组件名、发布者、来源和许可证说明，不能静默下载或执行。

## 3. 分层边界

### 3.1 Application

- 定义在线组件 id、类型、描述、安装进度和安装结果 DTO。
- 定义 `IOnlineComponentInstallationService` 窄端口，提供目录查询、已安装检测和显式安装命令。
- 预览 DTO 只携带稳定的 `RequiredComponentId`，不携带 URL、文件路径、HTTP 状态或 ZIP 细节。
- 预期失败使用 `Result / AppError`；取消保持取消语义。

### 3.2 Infrastructure

- 维护受信任组件注册表和包来源适配器。
- 负责 HTTPS 元数据查询、流式下载、大小限制、SHA-256 校验、ZIP 安全解压、暂存目录和原子安装。
- GitHub Release 包必须使用 API 返回的资产 digest 校验；digest 缺失、算法不支持、下载地址越过允许的仓库/主机或校验不一致时拒绝安装。
- ZIP 条目必须防止绝对路径、`..` 越界、条目数和解压总大小超限。必须先完整安装到 staging，再切换到最终目录；失败不得留下可被发现为“已安装”的半成品。
- 运行时工具发现继续只检查最终安装目录、应用目录和 PATH，不读取 Presentation 状态。

### 3.3 Presentation

- 把 Application 的组件描述格式化为本地化确认对话框。
- 安装期间投影统一后台任务状态、下载进度、成功通知和结构化失败日志。
- 对同一组件串行化确认/安装，避免多个预览并发弹窗或重复下载。
- 安装成功只触发当前仍相关的资产预览重载；标签已切换或请求已取消时不强制抢回前台。

## 4. 安全与更新规则

- 第一版只允许代码内注册的受信任来源，不接受远端目录直接提供任意可执行 URL。
- 下载重定向后的最终地址仍必须符合注册项允许的 HTTPS 主机和路径前缀。
- 下载压缩包和解压内容都必须有上限；不得把完整包无界读取进 UI 或 DTO。
- 组件版本由已安装可执行文件版本、长度和修改时间共同形成现有转码器缓存指纹。
- 第一版只在组件缺失时安装，不自动后台更新。未来插件在线更新必须再次走显式策略、版本比较、完整性校验和可回滚安装。
- 组件删除、更新管理和第三方许可证汇总后续可进入插件管理页；本轮不把运行时工具伪装成已有解密器/资源处理器插件。

## 5. 后续扩展

在线插件目录可复用：组件描述、用户确认、包来源、完整性校验、安全解压、staging 和安装结果；插件特有的 manifest 验证、兼容版本、签名/信任等级、启停和目录刷新应作为安装后的独立验证阶段，不得削弱本文件的下载安全规则。
