# AssestBundleTools 0.1.5

本版本重点完善批量拖拽替换、Spine skeleton 格式兼容和变更记录管理，并优化包含大量无关文件的工作区重新打开速度。

## 更新内容

- 普通资产的拖拽替换支持同时拖入多个文件与文件夹，应用会展开来源并按当前资产列表中的名称和 `[1] / [2]` 序号进行批量匹配；图片、音频、文本等不同类型可以在“全部类型”列表中一起处理。
- 批量匹配发现一个来源对应多个资源、多个来源对应同一资源或其他命名冲突时，会列出冲突文件并停止确认，不再静默选择可能错误的替换目标。
- 单个文件直接拖到明确资源行时继续沿用快捷替换逻辑，只校验目标支持的基本格式，不要求文件名与资源名完全相同；普通权限和管理员兼容拖放入口保持一致。
- Spine skeleton 替换始终以原始资产的 JSON / 二进制格式作为兼容基线；资源被替换过一次后，后续替换不会被新文件扩展名或上一替换来源错误限制。
- 修复 Spine skeleton 导出扩展名设置未在部分入口生效的问题。默认统一使用 `.skel`；启用内容感知命名后，JSON skeleton 使用 `.json`，二进制 skeleton 使用 `.skel`，并覆盖单项、拖拽、批量与工作区导出。
- 工作区来源扫描会完整排除当前工作区数据目录，避免把缓存、暂存、日志和索引再次当作导入候选，改善包含大量无关文件的工作区重开耗时。
- 资源详情“变更”页新增“复原原始资产”入口。确认后会原子清除当前资产、关联资源和 Spine 组成资产的全部内容修改记录并统一刷新；提取历史和外部文件会保留，任一记录校验失败时不会产生部分复原。
- 图文教程新增以音频为例的批量拖拽替换动态图和匹配规则说明。

## 下载说明

- `win-x64`：适用于大多数 Intel / AMD 64 位 Windows 电脑。
- `win-x86`：适用于需要 32 位兼容版本的 Windows 电脑。
- `win-arm64`：适用于 Windows on ARM 设备。
- `Portable.zip` 为便携免安装版本，`Installer.msi` 为安装版本。

未签名安装包可能触发 Windows SmartScreen 提示，请确认下载来源为本仓库的正式 Release。
