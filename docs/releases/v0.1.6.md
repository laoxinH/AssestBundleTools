# AssestBundleTools 0.1.6

本版本完善三类外部插件的分发与导入流程，并整理开发文档，统一插件协议、发布规则和当前开发路线的事实来源。

## 更新内容

- 插件管理页新增“导入插件包”入口，可直接选择插件文件夹或 ZIP 压缩包安装。
- AssetBundle codec、资源处理器和导出后处理器三类插件均可通过包内 manifest 自动识别，不再要求用户手动判断插件类别并逐项填写配置。
- 插件包导入会校验 `schemaVersion`、`kind`、插件 Id、入口文件、工作目录、启动参数和包内路径，拒绝路径越界、配置冲突或缺少必要文件的包。
- 三类插件统一采用当前清单规范；手动新增表单也会写入明确的 `schemaVersion` 与 `kind`，不再保留旧清单字段推断。
- ZIP 解压和目录安装使用临时目录校验及原子提交，导入失败不会留下半安装插件。
- 补充脚本型与 EXE 型测试插件的真实导入、发现和唤起回归，覆盖 codec、资源处理和导出后交接链路。
- 重整项目文档入口、设计索引、当前路线图和偏差登记，删除重复 UI 文档与未引用历史图片，明确插件协议和版本说明的唯一维护位置。

## 下载说明

- `win-x64`：适用于大多数 Intel / AMD 64 位 Windows 电脑。
- `win-x86`：适用于需要 32 位兼容版本的 Windows 电脑。
- `win-arm64`：适用于 Windows on ARM 设备。
- `Portable.zip` 为便携免安装版本，`Installer.msi` 为安装版本。

未签名安装包可能触发 Windows SmartScreen 提示，请确认下载来源为本仓库的正式 Release。
