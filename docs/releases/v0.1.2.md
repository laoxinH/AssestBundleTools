# AssestBundleTools 0.1.2

本版本完善导出扩展能力、使用文档和多窗口体验，并修复发布包中的离线文本编辑器资源。

## 更新内容

- 导出清单现在会记录每个输出资源包实际替换的资产，为第三方压缩、加密和归档工具提供稳定输入。
- 新增导出后处理插件类型；应用完成 AB 写出后可拉起插件并传递导出清单，插件可自行提供界面和后续处理流程。
- 插件管理页加入统一的三步式导出后插件编辑表单，并补充解密器、资源处理器和导出后处理插件的开发与导入说明。
- README 和用户指南新增从新建工作区、拖拽导入、普通资源/音频/Spine 替换到最终导出的图文演示。
- 修复 GitHub 发布包缺少离线 Monaco 资源的问题，文本预览与编辑不再因打包遗漏反复回退到原生文本视图。
- 修复切换主页面后可能重复打开批量提取、批量替换和保存新包窗口的问题；同类工作区操作窗口现在保持单实例。
- 资源预览/编辑窗口改用现代 WinUI 自定义标题栏；主窗口、批量操作、导出和资源编辑窗口统一使用系统 Mica 背景及兼容回退。
- 所有主要窗口的默认尺寸缩小为原设计的 80%，资源编辑窗口同时补齐 100%、125% 和 150% 系统缩放适配。

## 下载说明

- `win-x64`：适用于大多数 Intel / AMD 64 位 Windows 电脑。
- `win-x86`：适用于需要 32 位兼容版本的 Windows 电脑。
- `win-arm64`：适用于 Windows on ARM 设备。
- `Portable.zip` 为便携免安装版本，`Installer.msi` 为安装版本。

未签名安装包可能触发 Windows SmartScreen 提示，请确认下载来源为本仓库的正式 Release。
