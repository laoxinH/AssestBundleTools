# AssestBundleTools 0.1.3

本版本改善不同分辨率设备上的窗口使用体验，并修正纹理与音频资产大小的展示口径。

## 更新内容

- 主窗口会记忆用户最近一次调整后的正常窗口尺寸，重新启动后继续使用该尺寸。
- 工作区导出、批量提取、批量替换和独立资源编辑窗口会按工作区分别记忆窗口尺寸。
- 资产列表的大小列调整为“源大小”，纹理和音频优先显示 Unity 资产实际引用的源载荷长度，并继续支持按该大小排序。
- 资源详情会区分“源数据大小”和“序列化记录大小”，图片解码大小、音频转码结果大小不再覆盖资产基础信息。
- 修复旧工作区索引缓存可能导致 AudioClip 始终显示为 `172 B` 等对象记录大小的问题；打开或刷新工作区时会自动重建受影响的旧索引。

## 下载说明

- `win-x64`：适用于大多数 Intel / AMD 64 位 Windows 电脑。
- `win-x86`：适用于需要 32 位兼容版本的 Windows 电脑。
- `win-arm64`：适用于 Windows on ARM 设备。
- `Portable.zip` 为便携免安装版本，`Installer.msi` 为安装版本。

未签名安装包可能触发 Windows SmartScreen 提示，请确认下载来源为本仓库的正式 Release。
