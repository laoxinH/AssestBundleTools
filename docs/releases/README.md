# 版本说明维护规则

本目录中的 `v<SemVer>.md` 是正式 GitHub Release 正文和应用内更新详情的唯一来源。

## 发布要求

1. 推送正式 `v<SemVer>` tag 前，先新增同名 Markdown，例如 `v0.2.0.md`。
2. 标题明确版本，正文优先提供中文更新说明。
3. 按“新增、改进、修复、兼容性或已知问题”组织，只写用户能够观察到的变化。
4. 破坏性变化、数据迁移、插件协议变化和最低系统要求必须显式说明。
5. 不写本机路径、内部测试账号、临时下载地址或未公开样本信息。
6. Release workflow 找不到对应文件时必须失败，不能生成空白更新说明。

已发布文件视为不可变档案。后续修复通过新版本说明，避免仓库内容、GitHub Release 和应用内历史日志出现分叉。
