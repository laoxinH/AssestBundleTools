# AssestBundleTools 0.1.4

本版本重点完善 Spine 替换与导出兼容性、工作区资源包移除稳定性，并补充主题设置和首次使用引导。

## 更新内容

- Spine 组拖拽替换现在支持同时选择多个散文件，并继续支持文件夹匹配；存在同名文件夹与散文件冲突时会明确提示重新选择，避免静默采用错误来源。
- Spine skeleton 替换会根据实际载荷内容区分 JSON 与二进制格式，不再只依赖文件扩展名；格式不兼容时会在写入前拒绝并提供明确反馈。
- Spine skeleton 导出新增内容感知扩展名选项；默认继续统一导出为 `.skel`，启用后 JSON skeleton 使用 `.json`，二进制 skeleton 使用 `.skel`，并覆盖单项拖拽、批量和工作区导出链路。
- 修复二进制 TextAsset 替换后可能按文本重新编码的问题，导出时会保留原始字节，避免 Spine 二进制数据损坏。
- Sprite 的关联 Texture2D 替换入口移动到 Sprite 编辑区域底部操作栏，与保存、退出、撤销和重做操作保持同一上下文。
- 工作区移除资源包现在会等待导入阶段安全点、主动失效相关预览和缓存，并对已消失文件及清理失败提供可诊断结果，降低移除不生效或后台预览竞争导致异常退出的概率。
- 设置页新增跟随系统、浅色和深色主题选择；关于页新增当前版本与历史更新日志、发布/赞助页和使用教程入口。
- 首次启动会询问是否打开使用教程，并说明之后仍可从“设置与诊断 > 关于 > 使用教程”进入；选择结果只记录一次。

## 下载说明

- `win-x64`：适用于大多数 Intel / AMD 64 位 Windows 电脑。
- `win-x86`：适用于需要 32 位兼容版本的 Windows 电脑。
- `win-arm64`：适用于 Windows on ARM 设备。
- `Portable.zip` 为便携免安装版本，`Installer.msi` 为安装版本。

未签名安装包可能触发 Windows SmartScreen 提示，请确认下载来源为本仓库的正式 Release。
