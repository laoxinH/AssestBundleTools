# AssestBundleTools 0.1.1

本版本重点改善安装体验、高 DPI 显示和应用更新提示。

## 更新内容

- 新增标准 MSI 安装向导，可选择当前用户或所有用户、安装位置以及是否创建桌面快捷方式。
- 安装流程加入 MIT 开源许可展示与确认，同时保留 Velopack 的应用内更新能力。
- 修复 125% 和 150% 系统缩放下主窗口及批处理窗口尺寸过小、内容显示不完整的问题。
- 窄视口下自动收起侧边导航，改善笔记本屏幕和高缩放环境中的工作台可用空间。
- 更新确认窗口现在会显示当前目标版本的更新内容，并支持选择复制和滚动查看。
- 发布流程统一使用仓库内版本化更新说明，保证应用内说明与 GitHub Release 内容一致。

## 下载说明

- `win-x64`：适用于大多数 Intel / AMD 64 位 Windows 电脑。
- `win-x86`：适用于需要 32 位兼容版本的 Windows 电脑。
- `win-arm64`：适用于 Windows on ARM 设备。
- `Portable.zip` 为便携免安装版本，`Installer.msi` 为安装版本。

未签名安装包可能触发 Windows SmartScreen 提示，请确认下载来源为本仓库的正式 Release。
